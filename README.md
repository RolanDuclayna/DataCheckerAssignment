# DataCheckerAssignment
For this TDD process, I first created a method to simply return false. This would make it so that any month with 31 days would return false: a failing case. Then, I switched it to return true. This would make all 31 month days pass, but 30 month days also return true, thus a failing case for those months. Then I refactored it so that all months with 31 days would return true, then all months with 30 days would return false. Originally, I did not include February in any of these groups as the assignment said to handle February explicitly. However, I decided to group February with the 30 day group. Thus, February, along with all the other months with 30 days would return false. Then, I added an IllegalArgumentException if the user enters a null month, which I tested as well. Finally, I created an EnumSource Parameterized test that first tested just the months with 31 days, then tested all of the months, including a null month, to which it passed for all cases.
